# 🛍️ E-Commerce Order Price Classifier

An end-to-end Machine Learning web application that categorizes e-commerce order values into distinct price tiers (**Low**, **Medium**, **High**) based on transaction attributes.

Developed as part of **DecodeLabs Industrial Training — Project 2 (Data Classification)**.

---

## 📌 Project Overview
- **Goal:** Build a supervised learning classification model to predict sales price tiers from transaction metadata.
- **Model Accuracy:** **93.33%** using Random Forest Classification.
- **Interface:** Interactive Streamlit web dashboard for real-time inference and data visualization.

---

## 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** Pandas, Scikit-Learn, Streamlit, Plotly
- **IDE:** PyCharm Professional
